# repo-to-ai-brief v0.2.1

Trend-aligned release for coding-agent context workflows.

## Added

- `.gitignore` support by default.
- `--changed-only` mode for pull request and local edit reviews.
- Suggested coding-agent prompt template in the generated brief.

## Positioning

This release keeps the tool intentionally smaller than full repo packers: it produces a brief that a maintainer can inspect before giving it to a coding agent.

## Try It

```bash
PYTHONPATH=src python3 -m repo_to_ai_brief examples/sample_repo --max-files 8 --max-chars 1200
PYTHONPATH=src python3 -m repo_to_ai_brief . --changed-only --max-files 12 --max-chars 2000
```
